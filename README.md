## 🍽️ Highlights

- 🖨️ **Dynamic Printable Table QR Codes**: Generates high-DPI vector QR codes mapped to table numbers.
- ⚡ **Real-Time Price & Availability Sync**: Update 86'd items or prices instantly without reprinting paper menus.
- 🎨 **Brand Customization**: Custom restaurant logos, color palettes, and category filters.

git clone https://github.com/vickyiitp/QR-Menu-Generator-Demo.git
cd QR-Menu-Generator-Demo
npm install
npm run dev
