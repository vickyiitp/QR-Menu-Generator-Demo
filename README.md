# 🍽️ QR Menu Gen – Instant PDF to Digital Menu

**QR Menu Gen** is a premium Micro-SaaS solution designed for modern restaurants, cafes, and bars to transition from physical paper menus to a seamless, contactless digital experience in seconds.

---

## ⚡ The 10-Second Digital Upgrade

Stop overpaying for complex menu management systems. QR Menu Gen allows you to upload your existing PDF menu and instantly generates a professional, hosted digital menu with a high-resolution QR code ready for your tables.

### ✨ Key Features

- **🚀 Instant PDF to QR Conversion**: Upload your menu and get a live link + QR code in under 10 seconds.
- **📱 No App Required**: Customers scan the code with their smartphone camera and view the menu immediately. No downloads, no friction.
- **☁️ Cloud-Based Hosting**: Your menu is hosted on our ultra-fast, secure cloud infrastructure, ensuring 24/7 availability.
- **🎯 Precision QR Generation**: Download high-quality QR codes optimized for print—perfect for table tents, stickers, or posters.
- **💎 Premium UX/UI**: A sleek, minimal, and mobile-first interface designed to showcase your brand effortlessly.

---

## 🛠️ Technology Stack

This project is built using a modern, high-performance stack for maximum efficiency and scalability:

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **QR Engine**: `qrcode.react`
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: Optimized for Vercel/Cloudflare Workers

## 🚀 Getting Started (Developers)

1. **Clone the repository**:
   ```bash
   git clone https://github.com/vickyiitp/QR-Menu-Generator-Demo.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
